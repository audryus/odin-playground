# Starboarders

Starboarders is a 2D, grid-based, turn-based sci-fi strategy game where players command units and ships in tactical battles across a dynamic game board. 

## Game Concept

In Starboarders, players navigate a grid-based environment, managing resources and making strategic decisions to outmaneuver opponents. The game features various units and ships, each with unique abilities and characteristics.

## Installation

To get started with Starboarders, clone the repository and build the project:

```bash
git clone <repository-url>
cd starboarders
odin build.odin
```

## Running the Game

After building the project, run the game using the following command:

```bash
odin src/main.odin
```
